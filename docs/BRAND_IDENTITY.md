# Agent Desk — Brand Identity

## Name
**Agent Desk** — agents + a real desk (ops floor).

## Positioning
The command center for multi-agent work. Not another chat box — a desk with seats, queues, and approvals.

## Personality
Calm, sharp, cinematic ops. Competent. Never meme-loud.

## Logo
- Mark: signal-blue abstract desk / antenna “A” on void rounded square
- Wordmark: Agent Desk, Space Grotesk SemiBold, paper `#F2F4F8`
- Clear space = height of the mark

## Typography
Space Grotesk · Inter · JetBrains Mono

## Voice
- “Your agents. One desk.”
- “Needs you” (not “attention required”)
- “Seated” / “Idle” / “Blocked”
- Avoid: synergy, autonomous empire, AGI

## Promo
Dark backgrounds. Always show ≥2 agent avatars when explaining “team.”
Include an Approvals chip in at least one creative.
