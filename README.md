# Agent Desk

**Your agents. One desk.**

Phase 1 web app lives in [`web/`](web/). Reference kit (brand, avatars, prompts, UI samples) stays in this folder.

## Run the app

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). See `web/README.md` for routes and stack.

Accent: signal `#5B8CFF` on void `#0A0B10`. Lamp `#FFC857` means “Needs you.”

## Kit

| Folder | What’s inside |
|--------|----------------|
| `web/` | Next.js App Router app (Phase 1) |
| `prompt/` | Agent build prompt |
| `brand/` | Identity, tokens.css, logos |
| `ui-samples/` | Home, Desk, Agents, Approvals, Tasks, Analytics |
| `promo/` | Attach-ready copies for posts |
| `agent-avatars/` | 120 agent portraits (also copied to `web/public/agent-avatars`) |
| `resources/` | Fonts, favicons, SVG, promo templates |
| `docs/` | Pointers / extras |
